## 1. 通用响应结构规范

所有非流式 REST 接口统一返回以下标准包装结构：

```json
{
  "code": 200,
  "message": "success",
  "data": { ... }
}
```

* `code = 200`：请求成功；
* `code != 200`：业务或系统异常，`message` 包含人类可读的错误说明。

### 2.2 获取板块日内 240 点分时累积走势曲线
* **接口完整 URL**：`GET http://localhost:8080/api/dashboard/sector-flow/timeline`
* **请求方式**：`GET`
* **用途**：ECharts 折线图展示，绘制 09:31 ~ 15:00 全天 240 个点位的累计主力资金流入趋势。
* **请求参数 (Query)**：
  | 参数名 | 类型 | 必填 | 默认值 | 说明 |
  | :--- | :--- | :---: | :---: | :--- |
  | `trade_date` | string | 否 | 当天日期 | 格式 `YYYY-MM-DD` |
  | `sectors` | string | 否 | 空 | 逗号分隔的板块名称列表，如 `光伏设备,半导体,银行`。缺省时后端默认返回当天主力净流入前 5 板块 |
* **响应数据结构 (`data`)**：
  ```json
  {
    "code": 200,
    "message": "success",
    "data": {
      "trade_date": "2026-09-19",
      "time_series": [
        "09:31", "09:32", "09:33", "...", "11:30", "13:01", "...", "15:00"
      ],
      "sectors": ["光伏设备", "半导体"],
      "series_data": {
        "光伏设备": [18315820.0, 35431100.0, 52100000.0, 1582349000.0],
        "半导体": [-5200000.0, -12000000.0, 4300000.0, 680200000.0]
      }
    }
  }
  ```

### 2.3 获取特定历史时间切片快照 (时间滑块联动)
* **接口完整 URL**：`GET http://localhost:8080/api/dashboard/sector-flow/snapshot`
* **请求方式**：`GET`
* **用途**：前端拖动底部时间轴滑块（例如拖到 `10:30:00`）时，呈现该瞬间全市场各板块的资金分布柱状图。
* **请求参数 (Query)**：
  | 参数名 | 类型 | 必填 | 默认值 | 说明 |
  | :--- | :--- | :---: | :---: | :--- |
  | `trade_date` | string | 否 | 当天日期 | 格式 `YYYY-MM-DD` |
  | `snapshot_time` | string | 是 | - | 时间切片格式 `HH:MM:SS` (如 `10:30:00`) |
  | `top_n` | integer | 否 | `10` | 返回前 N 个板块 |

## 3. 智能体研报对话接口 (Python 提供，网关透传)

### 3.1 智能体实时流式对话 (SSE 打字机)
* **接口完整 URL**：`POST http://localhost:8080/api/agent/chat`
* **请求方式**：`POST` (Content-Type: `application/json`)
* **响应方式**：`text/event-stream` (Server-Sent Events)
* **请求体 (Body)**：
  ```json
  {
    "session_id": "sess_20260919_001",
    "prompt": "分析一下今天 10:00 之后为什么半导体板块资金快速流出？",
    "context_trade_date": "2026-09-19"
  }
  ```
* **SSE 事件流格式**：
  ```text
  event: thought
  data: {"thought": "正在调用本地时序数据库工具，查询半导体板块分时数据..."}

  event: message
  data: {"delta": "根据日内资金时序库记录，半导体板块在 10:02~10:15 期间，"}

  event: message
  data: {"delta": "超大单净流出达 4.2 亿元，主要受领跌股中芯国际异动影响..."}

  event: done
  data: {"status": "completed"}
  ```

## 5. 前端 Axios 封装模块 (`src/api/dashboard.ts`)

```typescript
import axios from 'axios';
import type { ApiResponse, RealtimeRankResponse, TimelineResponse } from '@/types/market';

// 统一指向微服务网关入口
const apiClient = axios.create({
  baseURL: 'http://localhost:8080/api/dashboard',
  timeout: 10000,
});

apiClient.interceptors.response.use(
  (response) => {
    const res = response.data;
    if (res.code !== 200) {
      console.error('API Error:', res.message);
      return Promise.reject(new Error(res.message || 'Error'));
    }
    return res.data;
  },
  (error) => {
    return Promise.reject(error);
  }
);

// 1. 获取最新排行榜
export const getRealtimeRank = (topN: number = 10): Promise<RealtimeRankResponse> => {
  return apiClient.get('/sector-flow/realtime', { params: { top_n: topN } });
};

// 2. 获取分时走势时序
export const getTimeline = (tradeDate?: string, sectors?: string[]): Promise<TimelineResponse> => {
  return apiClient.get('/sector-flow/timeline', {
    params: {
      trade_date: tradeDate,
      sectors: sectors?.join(','),
    },
  });
};

// 3. 获取特定切片快照
export const getSnapshot = (snapshotTime: string, tradeDate?: string, topN: number = 10): Promise<RealtimeRankResponse> => {
  return apiClient.get('/sector-flow/snapshot', {
    params: {
      snapshot_time: snapshotTime,
      trade_date: tradeDate,
      top_n: topN,
    },
  });
};
```

## 6. ECharts 看板走势图配置模板

针对 240 分钟分时折线图的 ECharts 经典金融配色方案：

```typescript
export const getTimelineChartOption = (timelineData: TimelineResponse) => {
  const series = Object.entries(timelineData.series_data).map(([sectorName, dataPoints]) => ({
    name: sectorName,
    type: 'line',
    smooth: true,
    showSymbol: false,
    lineStyle: { width: 2 },
    data: dataPoints.map((val) => Number((val / 100000000).toFixed(2))), // 转为“亿元”展示
  }));

  return {
    tooltip: {
      trigger: 'axis',
      valueFormatter: (value: number) => `${value} 亿元`,
    },
    legend: {
      data: timelineData.sectors,
      top: 10,
    },
    grid: {
      left: '3%',
      right: '4%',
      bottom: '10%',
      containLabel: true,
    },
    xAxis: {
      type: 'category',
      boundaryGap: false,
      data: timelineData.time_series,
      axisLabel: {
        interval: 29, // 约每半小时显示一个刻度标签 (09:30, 10:00, 10:30, 11:30, 13:30, 14:00, 14:30, 15:00)
      },
    },
    yAxis: {
      type: 'value',
      name: '主力净流入 (亿元)',
      splitLine: {
        lineStyle: { type: 'dashed' },
      },
    },
    series: series,
  };
};
```
