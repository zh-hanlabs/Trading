# A 股专业投研系统：日内板块资金看板 + 手搓 ReAct 智能体

> **定位**：基于「**Python 数据挖掘机与智能体 + PostgreSQL 高频时序库 + Java 业务中台与微服务网关 + Vue 3 终端**」构建的工业级 A 股量化看板与专业投研智能体系统。

---

## 核心架构与技术选型

本系统采用**职责严格解耦的高可用微服务就绪架构**：

```text
[外部数据源 (东财/腾讯/问财)] 
        │ 
        ▼ (爬取、清洗、增量计算、迟到开机自愈补数)
┌────────────────────────────────────────┐
│  agent-python (Python 3.11 引擎)       │
│   ├─ 1 分钟时钟采集器 (Collector)      │
│   └─ ReAct 智能体大脑 (@register_tool) │
└───────────────────┬────────────────────┘
                    │ 批量落库写入 (Writer)
                    ▼
┌────────────────────────────────────────┐
│  PostgreSQL 16 高频时序库 (:5432)      │
│  表: sector_fund_flow_snapshots        │
│  (1分钟切片 / 累计主力 / 瞬时增量 / 索引) │
└───────────────────┬────────────────────┘
                    │ 高速覆盖索引读取 (Reader)
                    ▼
┌────────────────────────────────────────┐
│  server-java (JDK 21 + Spring Boot 3)  │
│   ├─ trading-gateway   (微服务网关 :8080)
│   └─ trading-dashboard (看板中台 :8081)│
└───────────────────┬────────────────────┘

                    │ 统一 RESTful API / SSE 流式打字机
                    ▼
┌────────────────────────────────────────┐
│  web-vue (Vue 3 + Vite + ECharts 6)    │
│   ├─ 日内 240 点全天资金流时序图 (红进绿出)
│   ├─ 任意时刻滑块切片 Top10 排行柱状图  │
│   └─ 智能体交互抽屉 (深度研报生成)     │
└────────────────────────────────────────┘
```

## 阶段规划

- 🚀 **第一阶段（当前核心）：日内板块资金流向看板**
  - **Python 挖掘机**：周一至周五 09:30~15:00 每分钟轮询东财全市场 86 个板块，计算本分钟瞬时增量 $\Delta$；
  - **断点自愈机制**：开机自检，盘中迟到开机（如 12:00 启动）秒级回溯补齐当天缺失历史分钟线；
  - **PostgreSQL 16 存储**：高频时序快照持久化，建立唯一幂等防重索引与分时覆盖索引；
  - **Java 看板中台与网关**：基于 Spring Boot 3.3 + MyBatis-Plus 提供毫秒级 RESTful 出图接口；
  - **Vue 3 + ECharts 看板**：呈现全天累积走势折线图与时间滑块瞬间榜单柱状图。

- 🧠 **第二阶段：手搓 ReAct 智能体体系**
  - **自主工具注册器**：极简 `@register_tool` 装饰器，装配“本地时序库查询”、“i问财自然语言选股”等专属工具；
  - **Hermes 三明治上下文压缩引擎**：动态压缩长上下文，杜绝大模型注意力迷失；
  - **FastAPI SSE 流式长连接**：打字机式实时推理，由 Java 网关反向代理透传给前端对话抽屉。

- 🌐 **第三阶段：LangGraph 多智能体协同网络**
  - 多专家协同图谱（Supervisor 调度 + 资金面分析师 + 技术面分析师 + 基本面分析师）。
